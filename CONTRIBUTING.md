# Contributing

Thanks for your interest in this project.

This repository is public, but the project is proprietary and currently maintained by the Petrobolos Games team.

## External contributions
- We are not accepting unsolicited pull requests at this time.
- If you want to propose a change, open an issue first to discuss scope and licensing implications.

## Internal workflow
- Branch from `main`
- Run `npm ci` and `npm run build`
- Open a pull request with a clear summary and testing notes
